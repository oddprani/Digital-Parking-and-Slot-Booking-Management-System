# **App Name**: ParkSmart

## Core Features:

- User Authentication: Secure registration and login system for users to manage their parking bookings.
- Interactive Map Display: Display available parking locations with real-time slot availability and pricing details.
- Parking Slot Booking: Allow users to book parking slots by specifying entry and exit dates and times.
- Booking Management: Enable users to view their booking history, including active, completed, and cancelled reservations.
- Availability Calendar: Users can easily view which dates and slots are available at specific parking locations.
- Admin Interface: Admin user will see the real time view and the total active booking in all locations

## Style Guidelines:

- Primary color: Dark blue (#2C3E50) to convey trust and reliability.
- Background color: Light gray (#F4F4F8) for a clean, modern interface.
- Accent color: Teal (#3498DB) to highlight interactive elements and CTAs.
- Body and headline font: 'Inter' sans-serif for a clean, modern reading experience.
- Use simple, geometric icons to represent parking locations, types of parking, and booking status.
- Maintain a clear, consistent layout with intuitive navigation for easy booking and management.
- Incorporate subtle animations to confirm bookings and display real-time availability updates.
